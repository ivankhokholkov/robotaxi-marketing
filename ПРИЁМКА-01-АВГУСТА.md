## 8. Как проверить это самому

Всё, что написано выше, проверяется из папки одной командой каждое.

```bash
python3 .claude/scripts/wiki.py        # каталог, битые ссылки, связность, архитектура
ls .claude/skills                      # навыки
ls .claude/agents                      # агенты
cd ЛЕНДИНГ && bash build.sh            # пересборка страницы из данных
cat ЖУРНАЛ-РАБОТ.md                    # что сделано, по строке на материал
cat ПАМЯТЬ/РЕШЕНИЯ.md ПАМЯТЬ/ГРАБЛИ.md # почему сделано так и на чём обожглись
```

Состояние на 01.08.2026: битых ссылок 0, документов без входящих связей 0, нарушений архитектуры 0.
