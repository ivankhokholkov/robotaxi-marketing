# Ядро бренда

Что можно говорить о сервисе и чего нельзя. Читается перед любым материалом.

| Файл | О чём | Когда открывать |
|---|---|---|
| `АКТУАЛИЗАЦИЯ.md` | иерархия источников истины, что из какого документа, реестр открытого, ритуалы сессии | **первым, всегда** |
| `матрица-сегментов.md` | две оси сегментации в одной модели, правила по клеткам, противоречия документов | **вторым**, на этапе брифа |
| `позиционирование.md` | сегменты, сценарии, архетипы, УТП, рамки mandatory, лексика двух тонов, сплит-скрин | перед любым текстом |
| `стратегия-пилота.md` | ограничения пилота, две аудитории, три стадии, тэглайны, механики по стадиям | перед материалом под кампанию |
| `тон-чилл.md` | голос для 18–29 | материал на этот сегмент |
| `тон-сити.md` | голос для 30–45 | материал на этот сегмент |
| `стоп-слова.md` | запреты с причинами, включая формулировки самого заказчика | финальная вычитка |
| `rtb-факты.md` | продуктовые аргументы: подтверждённые и с метками | нужен довод или цифра |
| `цели.md` | цели бизнеса и маркетинга, воронка, критерии успеха | планирование, деки, аналитика |

## Правила этой папки

Файлы **читаются, а не переписываются по ходу работы**. Правка ядра — отдельное решение, а не побочный эффект написания поста.

Дословные цитаты заказчика внутри файлов не редактируются никогда: они помечены как цитаты и служат опорой, даже если звучат неудобно.

Если материал противоречит ядру — прав не материал. Если ядро противоречит профилю в корне папки — прав профиль, а ядро идёт в правку.

**Материалы заказчика не являются источником разрешённых формулировок.** Стратегия, продуктовая страница и презентации проверяются наравне с нашими текстами. При конфликте между формулировкой из документа заказчика и `стоп-слова.md` прав список запретов. Механика проверки — навык `brand-check`, раздел 11.
