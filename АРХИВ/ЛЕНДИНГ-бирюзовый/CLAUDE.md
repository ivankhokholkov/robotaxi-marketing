# Посадочная страница

Собирается из блоков. Каждый блок — отдельный файл, поэтому один блок перегенерируется без пересборки всей страницы.

## Как устроено

| Файл | Роль |
|---|---|
| `данные.yaml` | значения: города, даты, тарифы, числа. Правятся руками |
| `БЛОКИ/` | блоки страницы, по одному файлу |
| `КОМПОНЕНТЫ/` | повторяющиеся элементы |
| `tokens.css` | палитра, типографика, отступы, радиусы |
| `сборка.py` и `build.sh` | сборка страницы из блоков и данных |

## Как поменять цифру

Правится `данные.yaml`, затем запускается сборка. Страница обновится.

**Важно и неочевидно:** это меняет страницу, но не меняет тексты, которые система напишет дальше. Значение живёт ещё в профиле и в ядре бренда. Полный список мест — в [[rtb-факты]], раздел про изменение числа.

## Правила

Сборка не требует установки библиотек: это осознанное решение, чтобы страница собиралась на любой машине.

Значения с метками `[ПОДТВЕРДИТЬ]` печатаются при сборке предупреждением. Публиковать страницу с ними нельзя.
