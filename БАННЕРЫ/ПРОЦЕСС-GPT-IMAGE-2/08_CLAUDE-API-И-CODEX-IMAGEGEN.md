# 08. Claude/API и Codex imagegen

Весь процесс до момента запуска одинаков: бриф, style pack, референсы, промпт, один якорь. Отличается только способ вызова и сохранения результата.

## Общая классификация задачи

Для рекламных постов и баннеров указывать:

```text
Use case: ads-marketing
Asset type: finished campaign image for <channel and format>
```

Каждому входному изображению назначается роль:

- design-system reference;
- vehicle identity reference;
- real vehicle photograph;
- Moscow location reference;
- edit target;
- supporting detail reference.

Нельзя просто приложить набор изображений без объяснения их функций.

## Claude + API GPT Image 2

В поставке используется `.claude/scripts/картинка.py`. Скрипт:

- читает промпт из файла;
- передаёт референсы как изображения;
- сохраняет результат по `--out`;
- пишет стоимость в `БАННЕРЫ/ЖУРНАЛ-ГЕНЕРАЦИЙ.md`;
- не хранит API-ключ в проекте.

Рабочий запуск после создания папки кампании:

```bash
python3 .claude/scripts/картинка.py \
  --model openai/gpt-5.4-image-2 \
  --ref "БАННЕРЫ/brand/REFERENCE-CONTACT-SHEET.png" \
  --ref "БАННЕРЫ/brand/автомобиль/сводные-референсы/vehicle-turnaround-generated.png" \
  --ref "БАННЕРЫ/brand/автомобиль/реальные-фото/01_side-motion.png" \
  --prompt-file "РЕЗУЛЬТАТЫ/06_контент/2026-08-01_кампания/02_PROMPTS/01_anchor.txt" \
  --ar 3:4 --resolution 2K \
  --out "РЕЗУЛЬТАТЫ/06_контент/2026-08-01_кампания/03_RAW/01_anchor_a.png"
```

Для разных сюжетов выполняется отдельный вызов. Несколько вариантов одного сюжета получают суффиксы `_a`, `_b`, `_c`.

## Codex `$imagegen`

Обычная генерация и редактирование выполняются встроенным imagegen. API-ключ для этого не нужен.

Последовательность:

1. Создать папку кампании через `БАННЕРЫ/новая-кампания.py`.
2. Просмотреть локальные референсы перед использованием.
3. Вызвать imagegen с полным промптом и точным набором файлов.
4. Просмотреть результат и проверить якорный гейт.
5. Скопировать принятый результат из `$CODEX_HOME/generated_images/...` в `03_RAW/` командой `БАННЕРЫ/сохранить-imagegen.py`.
6. Не оставлять проектный файл только внутри `$CODEX_HOME`.
7. Записать фактический промпт и референсы в manifest.

Пример принятия результата:

```bash
python3 БАННЕРЫ/сохранить-imagegen.py \
  --source "/Users/USER/.codex/generated_images/SESSION/image.png" \
  --campaign "РЕЗУЛЬТАТЫ/06_контент/2026-08-01_кампания" \
  --name "01_anchor_a.png" \
  --stage raw
```

Скрипт не перезаписывает существующий файл: при совпадении имени создаёт версию `-v2`, `-v3`.

## Редактирование в Codex

Если целевой кадр существует только локально:

1. сначала открыть его инструментом просмотра изображений;
2. затем передать imagegen как edit target;
3. отдельно назвать supporting reference;
4. описать инварианты: `change only X; keep Y unchanged`;
5. сохранить исправленный кадр под новым именем.

Не обещать редактирование произвольного пути без предварительного просмотра изображения.

## CLI OpenAI как резерв

Встроенный imagegen остаётся предпочтительным для Codex. Не переходить молча на другой CLI или более старую модель. CLI OpenAI используется только по явному запросу пользователя или при подтверждённой необходимости параметров, недоступных встроенному режиму.

Для обычного контроля размера или пути CLI не нужен: сначала генерируется изображение, затем выбранный результат переносится в проект.

## Прозрачный фон

Для баннеров текущей системы прозрачный фон обычно не нужен. Если понадобится отдельный автомобиль или сенсор:

- встроенный imagegen сначала создаёт объект на ровном chroma-key фоне;
- фон удаляется локально;
- alpha-канал и края проверяются;
- финальный PNG сразу переносится в `01_REFERENCES/` или `04_FINAL/` кампании.

Истинную модельную прозрачность через другой CLI нельзя включать без отдельного подтверждения пользователя.
