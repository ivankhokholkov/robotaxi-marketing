Этот пример фиксирует отдельный style id `editorial-explainer`. Он не смешивается
с красной диагональной системой `kinetic-moscow` и остаётся в статусе `draft` до
пользовательского утверждения.

## Как изучать примеры

1. Сначала прочитать README примера.
2. Сравнить принятый кадр с забракованным.
3. Найти соответствующий промпт.
4. Проверить, какие референсы были переданы.
5. Посмотреть QA и только затем использовать приём в новой кампании.

Не копировать старый кадр буквально и не считать его требования площадки вечными.
