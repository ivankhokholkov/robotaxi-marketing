# Процесс генерации изображений с GPT Image 2

Эта папка превращает разрозненные правила проекта в один воспроизводимый маршрут. Она отвечает на вопрос: **что именно делать от брифа до сохранённого и проверенного изображения**.

## Быстрый маршрут

1. Заполнить [бриф](ШАБЛОНЫ/БРИФ.md).
2. Выбрать режим автомобиля и визуальную линию по [подготовке](01_ПОДГОТОВКА-И-БРИФ.md).
3. Передать в генерацию правильные изображения по [правилам референсов](02_РЕФЕРЕНСЫ.md).
4. Собрать промпт и сделать только один якорный кадр по [инструкции](03_ПРОМПТ-И-ЯКОРНЫЙ-КАДР.md).
5. Исправлять конкретные дефекты по [правилам итераций](04_ИТЕРАЦИИ-И-ПРАВКИ.md).
6. После утверждения якоря собрать нужные пропорции по [правилам форматов](05_ФОРМАТЫ-И-СБОРКА.md).
7. Прогнать [QA](06_QA-И-БРАК.md) и сохранить комплект по [структуре архива](07_ХРАНЕНИЕ-И-ПОВТОР.md).
8. Если генерация идёт из Claude/API или Codex, соблюдать [маршрут конкретного генератора](08_CLAUDE-API-И-CODEX-IMAGEGEN.md).
9. Результаты технической и визуальной проверки системы смотреть в [отчёте](09_ПРОВЕРКА-СИСТЕМЫ.md).

## Что открыть перед любой генерацией

В таком порядке:

1. `../СТИЛИ/registry.yaml` — выбрать один зарегистрированный style id.
2. Guide и contact sheet выбранного style pack; для стиля по умолчанию это `../brand/СТИЛЬ-Kinetic-Moscow.md` и `../brand/REFERENCE-CONTACT-SHEET.png`.
3. `../brand/ЧТО-ОТПРАВЛЯТЬ-В-ГЕНЕРАЦИЮ.md` — модель и конкретные файлы автомобиля.
4. `../formats.yaml` — размер, вес, охранные зоны и путь типографики.
5. `../2026-07-31_PRODUCTION-READY-МЕДИАСИСТЕМА.md` — режимы использования и статус материала.

Если эти файлы противоречат старой генерации, правы файлы, а не картинка.

## Два способа запуска

### Встроенный генератор Codex

Передать генератору изображения:

1. contact sheet выбранного style pack из `../СТИЛИ/registry.yaml`;
2. `../brand/автомобиль/сводные-референсы/vehicle-turnaround-generated.png`;
3. одну реальную фотографию нужного ракурса или локации;
4. при необходимости крупную надпись на двери или крышном модуле.

Затем отправить полный промпт одним сообщением. Для правки приложить исходный сгенерированный кадр и описать только исправляемый дефект.

### Скрипт поставки

Из корня `robotaxi-marketing`:

```bash
python3 .claude/scripts/картинка.py \
  --model openai/gpt-5.4-image-2 \
  --ref "БАННЕРЫ/brand/REFERENCE-CONTACT-SHEET.png" \
  --ref "БАННЕРЫ/brand/автомобиль/сводные-референсы/vehicle-turnaround-generated.png" \
  --ref "БАННЕРЫ/brand/автомобиль/реальные-фото/01_side-motion.png" \
  --prompt-file "путь/к/промпту.txt" \
  --ar 3:4 --resolution 2K \
  --out "путь/к/сырью/01_a.png"
```

Ключ берётся из `POLZA_AI_API_KEY` или внешнего `.env`; ключи в `ПОСТАВКА` не сохраняются. Скрипт автоматически записывает стоимость и файл в `../ЖУРНАЛ-ГЕНЕРАЦИЙ.md`.

Перед началом новой кампании лучше создать её папку командой:

```bash
python3 БАННЕРЫ/новая-кампания.py --type content --slug москва-видит-больше --style kinetic-moscow
```

Она создаст правильную структуру в `РЕЗУЛЬТАТЫ/`, скопирует бриф, QA и manifest и не перезапишет существующую кампанию.

## Какой результат считается готовым

Готовый результат — это не один удачный PNG. В папке кампании должны лежать:

- бриф;
- использованные референсы или ссылки на них;
- полные промпты;
- исходные генерации;
- отклонённые варианты с причинами;
- финальные изображения;
- контактный лист;
- заполненные QA и manifest.

## Важное ограничение

SMM-концепт и материал для платного размещения — разные статусы. В SMM GPT Image 2 может сгенерировать текст внутри кадра. Для РСЯ, UrbanAds и георекламы окончательный путь текста определяется `formats.yaml`; проверка площадки обязательна даже при визуально идеальной генерации.
