# GPT Image 2 Generation Process Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: execute this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. This delivery is not a Git repository, so verification is filesystem-based and no commit steps are included.

**Goal:** Собрать в `ПОСТАВКА` автономную и воспроизводимую документацию процесса генерации маркетинговых изображений Robotaxi Victor с GPT Image 2.

**Architecture:** Отдельная папка-процесс не дублирует существующие источники истины, а связывает их в последовательный маршрут: входной бриф → референсы → якорный кадр → целевые итерации → форматы → QA → архив. Нумерованные инструкции отвечают за этапы, шаблоны дают готовые артефакты, а примеры ведут к реальным принятым и забракованным генерациям.

**Tech Stack:** Markdown, YAML, plain-text prompts, existing `.claude/scripts/картинка.py`, `БАННЕРЫ/замер.py`, GPT Image 2.
