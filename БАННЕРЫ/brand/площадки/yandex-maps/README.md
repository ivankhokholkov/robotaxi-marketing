# Яндекс Карты: референс и шаблоны

`01_пример-баннера-в-маршруте.png` — пользовательский скриншот реального показа. По соотношению и механике он соответствует официальному формату «Баннер в Картах».

`официальные-шаблоны/` содержит загруженные 31.07.2026 файлы из справки Яндекса:

- `banner-1280x256.psd` — баннер при остановке или построении маршрута;
- `banner-1200x400.psd` — баннер карточки в составных геоформатах;
- `pin-200x200.psd` — пин;
- `billboard-official-template.psd` — официальный шаблон билборда;
- `banner-example.png` — официальный пример.

Перед экспортом сверять выходной PNG с `ПЛОЩАДКИ-И-ФОРМАТЫ-2026.md`. Имя или внутренний холст PSD не заменяют проверку фактического размера.
