# Реестр визуальных стилей

Style pack отделяет общий производственный процесс от конкретного визуального языка. Благодаря этому один и тот же конвейер работает с Kinetic Moscow, спокойной продуктовой линией или новым стилем заказчика.

## Как выбрать стиль

1. Открыть `registry.yaml`.
2. Выбрать один style id.
3. Передать только его guide, contact sheet и примеры.
4. Не смешивать два style pack в одном якорном кадре.
5. Записать style id в бриф и manifest.

Текущий утверждённый рекламный стиль — `kinetic-moscow`.

## Что содержит style pack

- короткое имя;
- статус;
- область применения;
- путь к полному guide;
- основной контактный лист;
- 3–6 принятых примеров;
- prompt preamble;
- неизменяемые признаки;
- антидрейф;
- отдельный чек-лист приёмки.

Для нового направления скопировать структуру из `ШАБЛОН-НОВОГО-СТИЛЯ.md`, заполнить её и добавить запись в `registry.yaml` только после утверждения якорного кадра.

## Что не является style pack

- один красивый случайный PNG;
- скриншоты Dribbble без описания применяемых приёмов;
- набор конфликтующих референсов;
- интерфейс сайта, автоматически перенесённый в рекламу;
- старая серия без промптов и QA.
