# Каталог блоков

Что можно взять из копии и куда смотреть. Имена — реальные классы CSS-модулей
Next.js: `ИмяКомпонента_элемент__хеш`. Искать по имени компонента:

```bash
grep -rn "ProductFeatures_" РАБОЧАЯ/КЛОН-роботакси/assets/*/**/css/*.css
```

Разметку смотреть в `<страница>/index.html`, вид — глазами на localhost:8899.

## Каркас, есть на всех страницах

| Компонент | Что это |
|---|---|
| `Header_header` | плавающая белая шапка-пилюля поверх контента, логотип слева, меню справа, бургер на мобильном |
| `TopMenu_topMenu` | меню с выпадающим подменю (`submenuPaper`), в подменю картинки-превью `MenuPictures` |
| `Container_container` | колонка 1440 с боковыми полями |
| `Layout_layout` | обёртка страницы |
| `Footer_footer` | подвал: описание, блоки ссылок, контакты, соцсети, копирайт, отдельная мобильная раскладка |
| `Button_button` | кнопка-пилюля |
| `Heading_heading` | заголовок, общий компонент для всех уровней |
| `ImgLoader_imgLoader` | обёртка картинки с ленивой подгрузкой |

## С чего начинать сборку продуктовой страницы

Рабочая последовательность, проверенная на трёх продуктовых страницах копии:

1. `ProductHero` — тёмная обложка
2. `ProductFeatures` — ряд плиток
3. `ProductSlider` — слайдер-рассказ
4. `ProductsBenefitsSlider` — польза списком 01–05 плюс фото
5. `RobotaxiDigits` — цифры
6. `ProductImpact` — тёмная секция-манифест
7. `ProductHowThisWork` — параллакс «как работает»
8. `ProductSafetySlider` — безопасность
9. `FAQ` — вопросы
10. `ProductContentBlock` — текст с кнопкой, финальное действие

Порядок не догма, но чередование светлого и тёмного держать: обложка тёмная,
манифест тёмный, между ними светлое.
