# Как собирать свои страницы на этом дизайне

Читать первым. Здесь правила игры, дальше — детали в трёх файлах:
`ДИЗАЙН-СИСТЕМА.md` (значения), `БЛОКИ.md` (паттерны), `КАРТИНКИ.md` (что есть из графики).

## Что это

Рядом лежит полная локальная копия сайта autonomy.yandex.ru (19 страниц, снята
31.07.2026). Из неё вынута дизайн-система: палитра, шкала кеглей, отступы,
радиусы, набор блоков. Своё берётся отсюда, а не придумывается заново.

## Главное правило

**Не изобретать новый визуальный язык.** Новая страница собирается из блоков,
которые уже есть в копии: те же фоны, те же скругления, та же типографика, та
же ритмика секций. Меняются тексты, картинки и порядок блоков — не система.

Если для задачи нужного паттерна в `БЛОКИ.md` нет, сначала проверить остальные
18 страниц копии: скорее всего он там уже есть. Заводить новый паттерн — только
когда его точно нет.

## Порядок работы

1. Открыть копию и посмотреть глазами:

   ```bash
   cd "РАБОЧАЯ/КЛОН-роботакси" && python3 -m http.server 8899
   ```

   Страница роботакси — http://localhost:8899/products/robotaxi/

2. Составить список блоков будущей страницы по `БЛОКИ.md`: какой паттерн под
   какую мысль.
3. Подобрать картинки по `КАРТИНКИ.md`. Чего не хватает — выписать бриф на
   генерацию, а на место поставить заметную заглушку, не пустоту.
4. Подключить `ДИЗАЙН/токены.css` и верстать блок за блоком, сверяясь с
   оригиналом на 1440 и на 375.
5. После каждого блока — показать. Не собирать всю страницу молча.

## Чего не делать

- **Не тащить чужие фотографии и логотип в публикуемый материал.** Съёмки в
  `static/images/` сняты с сайта Яндекса. Для примерки и внутреннего показа
  годятся, для выпуска нужны свои.
- **Не менять палитру под настроение.** Чёрный `#1a1a1a`, серый фон `#f4f4f6`,
  белый — это костяк. Цветные акценты в системе есть, но их роль — точечная.
- **Не подменять шрифты.** YSText и YSTextCond лежат в копии, подключены
  локально. Без них страница разваливается: вся крупная типографика построена
  на узком начертании.
- **Не выпускать фактуру, не проверив её по правилам проекта.** Дизайн — из
  копии, а тексты и цифры по-прежнему живут по `БРЕНД/` и `knowledge/`: цифра
  без карточки на страницу не идёт.

## Что уже проверено

Копия отдаёт все 19 страниц, 672 ссылки на стили, шрифты, скрипты и картинки
живые, битых нет. Геометрия страницы роботакси совпадает с оригиналом до
пикселя на 1440 и на 375. Метрика Яндекса отключена.
