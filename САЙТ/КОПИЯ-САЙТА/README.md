# Копия сайта autonomy.yandex.ru

**Опирается на:** [[ОТКУДА-ДИЗАЙН]]

Полное локальное зеркало сайта «Яндекс Автономный транспорт» на дату
**31.07.2026**: 19 страниц, работает офлайн, правится руками.

Копия сделана по согласованию с заказчиком, под доработку. Это не публикация:
не выкладывать в открытый доступ под чужим брендом.

## Собрать свою страницу на этом дизайне

Разбор дизайн-системы и наша страница пилота живут рядом, на уровень выше:

| Где | Что |
|---|---|
| `САЙТ/index.md` | вход в раздел |
| `САЙТ/ДИЗАЙН-СИСТЕМА/` | палитра, шкалы, каталог блоков, токены |
| `САЙТ/СТРАНИЦА/` | готовая страница пилота |
| `САЙТ/ИСХОДНИКИ/` | её блоки и сборщик |

Эта папка нужна как источник: из неё берутся классы, стили, шрифты
и композиция блоков. Здесь ничего не правится.

## Как запустить

```bash
cd "РАБОЧАЯ/КЛОН-роботакси" && python3 -m http.server 8899
```

Открыть http://localhost:8899/. Главная страница роботакси —
http://localhost:8899/products/robotaxi/

Обязательно через сервер, а не двойным кликом по файлу: ассеты подключены
корневыми путями, по `file://` они не найдутся.

По всем 19 страницам проверены 672 ссылки на картинки, стили, шрифты и скрипты
— битых нет.

Совпадение точное, потому что копия использует те же самые файлы стилей и
JS-бандлы, что и прод, а не пересобранную вёрстку.

## Что изменено против оригинала

1. **Метрика Яндекса отключена.** Ссылки `mc.yandex.ru` заменены на пустышку
   `/static/_noop/metrika/`, чтобы копия не слала хиты в чужой счётчик.
2. **Ссылки на CDN переписаны** на локальные корневые `/assets/...`.
3. **Относительные `src="static/..."`** сделаны корневыми: на проде страница
   живёт без слеша в конце, локально — со слешем, иначе путь съезжает.

Больше ничего не трогалось.

## Что осталось внешним

- Видеоплеер `runtime.strm.yandex.ru` («История роботакси») — локально не
  воспроизводится.
- Формы Яндекса `forms.yandex.ru`.
- Ссылки на внешние ресурсы: `yandex.ru`, `disk.yandex.ru`, `sdg.yandex.ru`.

## Как дорабатывать

Вёрстка живёт в CSS-файлах `assets/.../css/` — CSS-модули Next.js с хешами в
именах классов (`ProductHero_hero__YkcWn`). Текст и структура — в `index.html`
страницы и в JSON внутри `<script id="__NEXT_DATA__">` в конце файла.

Порядок правки:

1. Текст и картинки — в HTML страницы и в `static/images/`.
2. Стили — либо точечно в существующих CSS-файлах, либо своим файлом
   `custom.css`, подключённым последним: так правки не потеряются при
   повторном зеркалировании.
3. JS-бандлы минифицированы, менять поведение сложно. Нужна новая логика —
   проще дописать свой скрипт в конец страницы.

**Важно:** после гидратации React перерисовывает разметку из `__NEXT_DATA__`.
Поправишь текст только в HTML — он вернётся к исходному, когда загрузится JS.
Менять надо в обоих местах: и в разметке, и в JSON `__NEXT_DATA__`
(а для переходов между страницами — ещё и в `_next/data/<buildId>/*.json`).

## Обновить зеркало

```bash
cd "РАБОЧАЯ/КЛОН-роботакси/_src" && node mirror-all.mjs
```

Скрипт обходит страницы из списка `PAGES` плюс все внутренние ссылки, которые
найдёт (потолок — 80 страниц). Перезапись затрёт ручные правки в HTML и в
`assets/`. Свои изменения держать отдельным файлом.
