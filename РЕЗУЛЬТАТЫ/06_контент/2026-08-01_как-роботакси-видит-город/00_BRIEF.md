# Бриф: «Как роботакси видит город»

## Задача

- Получить шестикарточную редакционную карусель 4:5 с текстом внутри изображения.
- Объяснить систему восприятия автономного автомобиля без обещаний безопасности и сравнения с человеком.
- Проверить новый style id `editorial-explainer` отдельно от `kinetic-moscow`.
- Критерий успеха: карточки читаются как один взрослый продуктовый материал, а не как шесть рекламных постеров.

## Аудитория

- Горожане 25–45 лет, которым интересно, как работает роботакси.
- Стадия: знакомство и понимание продукта.
- Главный барьер: технология выглядит сложной и непрозрачной.

## Статус

- Статус: SMM-концепт, `demo-only` до бренд- и юридического согласования.
- Автомобиль: `Official Branded`.
- Площадка: Telegram / VK / презентация.
- Формат финала: 1080×1350.

## Визуальная линия

- Стиль: `editorial-explainer`.
- Строгая модульная сетка, крупная узкая кириллица, короткий абзац и один предметный визуал на карточку.
- Палитра: кислотно-жёлтый, холодный серый, тёплый белый, чёрный; красный только как микроакцент.
- Ритм: обложка → цифры → восприятие → распознавание → прогноз и план → итоговый процесс.
- Исключить: Telegram UI, шапку канала, копирование исходных макетов, fake UI, dashboard, HUD, метро, карты, координаты, придуманные цифры, обещания безопасности.

## Точный текст

1. `КАК РОБОТАКСИ ВИДИТ ГОРОД?` / `6 КАРТОЧЕК О СИСТЕМЕ ВОСПРИЯТИЯ`
2. `9 КАМЕР` / `4 ЛИДАРА` / `6 РАДАРОВ` / `СЕНСОРЫ СОБИРАЮТ ДАННЫЕ ОБ ОКРУЖАЮЩЕЙ СРЕДЕ`
3. `ВОСПРИЯТИЕ` / `СИСТЕМА СОБИРАЕТ ДАННЫЕ И ПЕРЕДАЁТ ИХ В ВЫЧИСЛИТЕЛЬ`
4. `РАСПОЗНАВАНИЕ` / `СИСТЕМА ФОРМИРУЕТ КАРТИНУ. НЕЙРОСЕТЬ РАСПОЗНАЁТ ОБЪЕКТЫ`
5. `ПРОГНОЗ И ПЛАН` / `СИСТЕМА РАССЧИТЫВАЕТ ДВИЖЕНИЕ УЧАСТНИКОВ И ОПРЕДЕЛЯЕТ ДАЛЬНЕЙШИЕ ДЕЙСТВИЯ`
6. `ОТ ДАННЫХ К ДВИЖЕНИЮ` / `ВОСПРИЯТИЕ → ВИЗУАЛИЗАЦИЯ → ЛОКАЛИЗАЦИЯ → ПРОГНОЗ → ПЛАНИРОВАНИЕ → УПРАВЛЕНИЕ`

У каждой карточки есть индекс `N/6`. Других слов в кадре быть не должно, кроме штатной маркировки автомобиля.
