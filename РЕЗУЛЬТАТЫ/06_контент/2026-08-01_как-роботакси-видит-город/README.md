# «Как роботакси видит город»

Шестикарточная объясняющая карусель и первый тест нового style id `editorial-explainer`.

- Дата: 2026-08-01.
- Формат: 1080×1350, 4:5.
- Статус кампании: `demo-only`.
- Статус стиля: `draft` до пользовательского утверждения.
- Режим автомобиля: `Official Branded`.
- Генерация: встроенный Codex `imagegen`, текст внутри изображения.

## Структура

1. Обложка — `КАК РОБОТАКСИ ВИДИТ ГОРОД?`
2. Факт — `9 КАМЕР / 4 ЛИДАРА / 6 РАДАРОВ`
3. Предметный разбор — `ВОСПРИЯТИЕ`
4. Городской пример — `РАСПОЗНАВАНИЕ`
5. Следующий этап — `ПРОГНОЗ И ПЛАН`
6. Итоговая схема — `ОТ ДАННЫХ К ДВИЖЕНИЮ`

## Где что лежит

- `01_REFERENCES/` — пользовательские примеры, собранные в стилевой лист.
- `02_PROMPTS/` — полный промпт каждой карточки.
- `03_RAW/` — исходные генерации и папка `rejected/`.
- `04_FINAL/` — шесть технических мастеров 1080×1350.
- `05_QA/QA.md` — фактическая приёмка и ограничения.
- `КОНТАКТНЫЙ-ЛИСТ.png` — вся серия одним изображением.

## Важные решения

- Это отдельный редакционный стиль; красная диагональная система `Kinetic Moscow` здесь не используется.
- Из примеров Яндекса перенесены только модульная иерархия, ритм и типы карточек. Telegram-обвязка, готовые композиции и интерфейсы не копировались.
- Два дефектных варианта были отбракованы до финала: человек на переднем сиденье и географически невозможный фон с Кремлём и Москва-Сити.
- Встроенный генератор вернул более узкие вертикальные исходники. Для мастеров 4:5 вся композиция сохранена без растяжения и обрезания; свободные боковые области продолжены из цвета краёв изображения.
- Предметная раскладка компонентов на карточке 3 является иллюстрацией, а не инженерной схемой реального устройства.
