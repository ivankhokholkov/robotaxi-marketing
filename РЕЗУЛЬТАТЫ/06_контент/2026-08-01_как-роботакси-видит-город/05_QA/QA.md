## 1. Текст и факты

- [ ] Заголовок совпадает с брифом посимвольно.
- [ ] Вторичная строка совпадает с брифом.
- [ ] Переносы, тире, кавычки и `Ё` корректны.
- [ ] В кадре нет лишних слов и псевдобукв.
- [ ] Все продуктовые факты имеют источник.
- [ ] Нет неподтверждённого обещания `без водителя`.

## 2. Автомобиль

- [ ] Белый fastback-седан, а не кроссовер или концепт.
- [ ] Фары, решётка, колёса и оконная линия совпадают.
- [ ] Крышный модуль низкий и широкий.
- [ ] Лицевая панель крышного модуля чёрная.
- [ ] Башня лидара короткая и тёмная.
- [ ] Оклейка состоит из отдельных многоугольников с белыми промежутками.
- [ ] Бортовая надпись не потеряна и не искажена.
- [ ] Крышная надпись корректна, если её сторона видна.
- [ ] На обоих передних сиденьях не видно людей.
- [ ] Пустое водительское место не является смысловым центром.

## 3. Стиль и Москва

- [ ] Выбранная визуальная линия считывается.
- [ ] Есть 5–9 функциональных слоёв без визуального шума.
- [ ] Автомобиль, типографика и Москва образуют одну композицию.
- [ ] Есть минимум две крупности продукта.
- [ ] Локация узнаваема и географически правдоподобна.
- [ ] Нет туристического клише без смысловой причины.
- [ ] Нет fake UI, HUD, карт, метро, координат и псевдоданных.
- [ ] Нет рваной бумаги, grunge, glassmorphism и фиолетового неона.

## 4. Площадка

- [ ] Пиксельный размер точный.
- [ ] Формат файла разрешён.
- [ ] Вес ниже лимита.
- [ ] Заголовок соответствует минимальному кеглю.
- [ ] Все важные элементы внутри охранной области.
- [ ] Оставлено место под автоматическую пометку площадки.
- [ ] Доля текста соответствует требованиям.
- [ ] Макет не выглядит частью интерфейса Яндекса.
- [ ] Юридическая маркировка подтверждена.

## 5. Фактический размер просмотра

- [ ] Заголовок читается в реальном масштабе показа.
- [ ] Автомобиль узнаётся без увеличения.
- [ ] Обязательная маркировка не превращается в визуальный шум.
- [ ] В течение секунды понятен главный тезис.
