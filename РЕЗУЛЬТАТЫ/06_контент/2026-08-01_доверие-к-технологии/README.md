# «Доверие начинается с понимания»

Готовая серия из четырёх вертикальных карточек о восприятии города автономным автомобилем.

- Дата: 2026-08-01.
- Style id: `kinetic-moscow`.
- Формат: 1080×1350, 4:5.
- Статус: `demo-only` до бренд- и юридического согласования.
- Генерация: встроенный Codex `imagegen`, текст внутри изображения.

## Состав серии

1. `ДОВЕРИЕ НАЧИНАЕТСЯ С ПОНИМАНИЯ`
2. `КАМЕРЫ ЛИДАРЫ РАДАРЫ`
3. `ГОРОД В ПОЛЕ ЗРЕНИЯ`
4. `ТЕХНОЛОГИЯ СТАНОВИТСЯ ПОНЯТНЕЕ`

Финалы лежат в `04_FINAL/`, исходные генерации — в `03_RAW/`, полные промпты — в `02_PROMPTS/`. Сводный просмотр серии: `КОНТАКТНЫЙ-ЛИСТ.png`.

## Обязательный бренд-лок автомобиля

На чёрной лицевой панели крышного модуля слева направо должны стоять три отдельные части:

1. красный круг с белой кириллической `Я`;
2. отдельный маленький многоцветный знак-отпечаток/сфера;
3. белая надпись `Автономный транспорт`.

Нельзя убирать второй знак, сливать два знака в один, заменять последовательность словом `Яндекс` или оставлять панель пустой. Для крупного плана эта деталь проверяется посимвольно; на общем плане она должна сохранять правильную цветовую и композиционную структуру.
