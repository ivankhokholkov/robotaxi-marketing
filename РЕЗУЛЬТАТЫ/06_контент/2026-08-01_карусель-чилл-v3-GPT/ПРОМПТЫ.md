# Промпты карусели «Садись и выдохни» v3

Модель одна на все кадры: `openai/gpt-5.4-image-2`, `--ar 3:4 --resolution 2K`, 7 ₽ за вызов.
Текст вплавлен генерацией, кодом не накладывался.

Порядок референсов — по `БАННЕРЫ/brand/ЧТО-ОТПРАВЛЯТЬ-В-ГЕНЕРАЦИЮ.md`:
контактный лист → раскадровка автомобиля → фото локации/движения → макро надписи.

```bash
set -a; source /Users/ivankhokholkov/Documents/robotaxi-victor/.env; set +a
cd "ПОСТАВКА/robotaxi-marketing"
python3 .claude/scripts/картинка.py --model openai/gpt-5.4-image-2 \
  --ref "БАННЕРЫ/brand/REFERENCE-CONTACT-SHEET.png" \
  --ref "БАННЕРЫ/brand/автомобиль/сводные-референсы/vehicle-turnaround-generated.png" \
  --prompt-file "<путь>/промпты/01.txt" --ar 3:4 --resolution 2K --out кадр.png
```

## Какие референсы уходили в каждый принятый кадр

| Финал | Исходник | Референсы, ушедшие в этот вызов |
|---|---|---|
| 01 | `01_c` | контактный лист + раскадровка |
| 03 | `03_b` | контактный лист + CAR-IDENTITY-LOCK\* |
| 04 | `04_b` | контактный лист + CAR-IDENTITY-LOCK\* + `надпись-на-двери` |
