# «Москва видит больше» — рабочая серия

Четыре арт-дирекционных концепта на основе реального автомобиля и разных московских контекстов: Зарядье, ВДНХ, Лужники, ЗИЛАРТ.

- `raw/` — полные генерации 1003×1568;
- `social-1080x1350/` — адаптации без потери содержания;
- `CAMPAIGN.md` — логика кампании и фактические ограничения;
- `PROMPTS.md` — промпты серии.

Статус: **концепт, не финал для размещения**. Текущие социальные адаптации используют расширение фона по бокам. Для публикации лучше перегенерировать утверждённый кадр сразу под точный 1080×1350 и заново проверить кириллицу.

Эта серия используется как доказательство удачного направления: продуктовая наглядность, крупная типографика, несколько уровней глубины, контролируемые красные акценты и разнообразие московских локаций.
