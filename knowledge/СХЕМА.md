# Схема контура знаний

Конвенции базы. Читается перед любой операцией с `knowledge/`. Процесс — в навыке `wiki`.

## Три слоя

| Слой | Где | Кто пишет | Правится ли |
|---|---|---|---|
| Сырьё | `references/` | ресёрчер при скрейпе | **никогда.** Снимок источника неизменяем |
| Карточки | `market/`, `competitors/`, `regulation/`, `audience/`, `barriers/`, `channels/` | модель | обновляются при новых данных |
| Синтез | `ХАБЫ/` | модель | переписываются, когда меняется картина |

Карточка отвечает на «какая цифра и откуда». Хаб отвечает на «что из этого следует». Смешивать нельзя: хаб без карточек — это мнение, карточки без хаба — груда фактов, которую никто не собирает в вывод.

## Карточка

Обязательные поля заголовка: `type`, `title`, `description`, `resource`, `status`, `generated`, `stale_after`, `sources` со снимком и уровнем достоверности.

Правила:

- нет ссылки и снимка — карточки не существует
- дословная цитата только в блоке цитирования, остальное помечается как пересказ
- одна карточка — один проверяемый факт, а не тема целиком
- расхождение между источниками фиксируется в самой карточке, а не сглаживается

## Когда читать снимки

Никогда в обычной работе. Снимок открывается в трёх случаях: при ингесте, при перепроверке протухшей карточки и в споре о формулировке.

Причина простая. Вопрос через хаб и две карточки стоит около пяти тысяч токенов, тот же вопрос через снимки — вдвое дороже, а вся база одним куском — четверть миллиона. Дробление на слои существует ради этой разницы.

Снимки нормализованы: убраны навигация и пустые блоки, полные оригиналы лежат сжатыми в `references/_полные/`. Доказательность сохраняется, вес падает.

Новые снимки нормализуются командой:

```bash
python3 .claude/scripts/snapshots.py check   # сколько мусора
python3 .claude/scripts/snapshots.py clean   # почистить, оригиналы сжать
python3 .claude/scripts/snapshots.py prune   # найти снимки без карточек
```

## Сроки годности

Регуляторика 180 дней, конкуренты 30, опросы 365, требования площадок 30. Просроченная карточка не используется в материалах до перепроверки.

## Пороги создания

Хаб заводится, когда тема собрана минимум из трёх карточек либо когда она центральная для решения. Ниже порога — раздел внутри существующего хаба.

## Связи

Хабы ссылаются на карточки викилинками. Карточка без входящей ссылки — сирота: либо она не нужна, либо хаб не дописан. Линт показывает такие отдельно.

## Операции

```bash
python3 .claude/scripts/wiki.py index   # пересобрать каталог
python3 .claude/scripts/wiki.py lint    # проверить здоровье базы
python3 .claude/scripts/wiki.py         # и то, и другое
```

Каталог собирается автоматически и руками не правится. Журнал `log.md` дописывается при каждой операции.
