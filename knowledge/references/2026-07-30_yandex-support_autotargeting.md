# Автотаргетинг

Автотаргетинг — это технология показа объявлений, не использующая ключевые фразы. Она анализирует информацию в объявлении и на странице перехода и определяет, соответствует ли объявление поисковому запросу, интересам пользователя или тематике площадки. Автотаргетинг позволяет получить дополнительный целевой трафик благодаря показам аудитории, которую сложно охватить с помощью ключевых фраз.

## Принципы работы

На поиске

В сетях

Для показа на поиске автотаргетинг в режиме реального времени подбирает объявления, у которых заголовок (без дополнительного заголовка), текст и страница перехода более всего соответствуют запросу пользователя. При этом учитывается множество факторов: возможные синонимы, формы слов, родственные тематики, заданные для кампании и группы объявлений [минус-фразы](https://yandex.ru/support/direct/ru/keywords/negative-keywords) и т. д.

Например, объявление с текстом про путешествия в космос и продвигаемой страницей `в-космос.рф` может быть показано по запросу _туры на марс_.

![](https://cdn-viewer.diplodoc.com/docs-assets/support-direct-pro/rev/r20512751/ru/_assets/autotargeting.png)

Для подбора объявлений в сетях автотаргетинг анализирует в первую очередь известную информацию об интересах пользователя. Если этой информации недостаточно (например, пользователь выходит в интернет с нового компьютера или недавно удалил файлы cookie), технология ориентируется на тематику площадки.

Например, объявление о продаже туров на Марс может увидеть пользователь, который интересуется космосом. А пользователь, о котором ничего не известно, увидит такое объявление на странице с похожей тематикой.

![](https://cdn-viewer.diplodoc.com/docs-assets/support-direct-pro/rev/r20512751/ru/_assets/autotargeting_net.png)

#### Почему полезно включать автотаргетинг

Ключевые фразы в сетях позволяют нацелиться только на тех пользователей, которые явно проявляли интерес к тематике, заданной именно этими фразами. Автотаргетинг не опирается на конкретные формулировки и позволяет показывать ваши объявления пользователям, которые интересовались родственными тематиками или похожими товарами. Таким образом, с включенным автотаргетингом вы можете расширить аудиторию показа, не подбирая вручную большого количества ключевых фраз.

Автотаргетинг работает параллельно с ключевыми фразами в равном приоритете. Статистика показов по автотаргетингу будет учитываться отдельно.

Примечание

Автотаргетинг работает эффективнее, если использовать его вместе с конверсионными стратегиями. Для этого установите на сайт счетчик [Яндекс Метрики](https://yandex.ru/support/direct/ru/statistics/metrika) и настройте в нем цели.

## Настройки автотаргетинга на поиске и в Картах

#### Категории запросов

- **Целевые запросы** — объявление точно отвечает на запросы пользователя. Например, для организации `в-космос.рф` с объявлением «Путешествия в космос» целевым запросом будет _купить путешествие в космос_.

- **Узкие запросы** — объявление шире, чем запросы пользователя. Например, для организации `в-космос.рф` с объявлением «Путешествия в космос» узким запросом будет _купить романтическое путешествие в космос_.

Ранее узкие запросы относились к целевым. Поэтому в текущих кампаниях с настроенными целевыми запросами будут включены две категории: узкие и целевые. При необходимости это можно изменить.

- **Широкие запросы** — пользователь пишет запрос, не указывая на конкретный продукт, и ваше предложение входит в эту категорию. Например, _выбрать тур_.

- **Альтернативные запросы** — пользователь ищет продукт, который можно заменить на тот, который вы продвигаете. При этом объявление также может удовлетворить запрос. Например, _купить подводный тур_.

- **Сопутствующие запросы** — запросы по продуктам, которые могут быть интересны вместе с продвигаемым товаром или услугой. Например _купить скафандр_.

В Единой перфоманс-кампании, если в группу добавлены текстово-графические объявления, для категорий показываются примеры запросов, по которым будет срабатывать автотаргетинг.

Внимание

С 30 июня текстово-графические объявления в Единых перфоманс-кампаниях доступны только для редактирования. Для задач, которые раньше решались с помощью текстово-графических объявлений, создавайте [комбинаторные](https://yandex.ru/support/direct/ru/unified-performance-campaign/create-comb-ad).

С 14 июля началось обновление существующих текстово-графических объявлений до комбинаторных. Подробнее — на странице [Обновление текстово-графических объявлений до комбинаторных](https://yandex.ru/support/direct/ru/unified-performance-campaign/upgrade-to-comb).

#### Упоминание брендов в запросах

- **Запросы с упоминанием вашего бренда**, например, для спортивного магазина «Атлет»: _купить кроссовки атлет_, _футболки для спорта атлет_.

- **Запросы с упоминанием брендов конкурентов**, например, _купить кроссовки в мир спорта_, _футболки для спорта в магазине олимпика_.

- **Запросы без упоминания вашего бренда или брендов конкурентов**, например, _недорогие кроссовки_, _купить футболку для спорта_.

Вы можете использовать автотаргетинг в отдельных кампаниях для брендовых запросов. Или комбинировать категории и упоминание не только своего бренда, но и бренда конкурентов. Брендовыми запросами считаются те, по которым этот же бренд идет первым в органической выдаче или является непосредственным производителем. Например, если ваша кампания «Добрая реклама» помогает с настройкой Директа и вы размещаете про это объявление, то запрос _Добрая реклама_ будет для вашей кампании брендовым запросом, а запрос _Директ_ — не будет.

Примеры запросов автотаргетинга в разных категориях будут меняться в зависимости от настроек упоминания бренда.

Категории автотаргетинга и брендовые категории работают совместно через логический оператор «И».

Особенности настройки автотаргетинга в Единой перфоманс-кампании и в Мастере кампаний — в блоке [Как настроить автотаргетинг в кампании](https://yandex.ru/support/direct/ru/impression-criteria/autotargeting#autoy_on).

#### Примеры запросов: в отдельном окне или в файле

Примеры запросов для Единой перфоманс-кампании, если в группу добавлены объявления, можно посмотреть в отдельном окне или скачать в XLSX-файле в блоке справа от настроек категорий. Примеры формируются с учетом заданных текстов, заголовков и ссылок, настроек упоминания бренда и минус-фраз. В окне и файле будут примеры запросов во всех категориях. Опирайтесь на них, чтобы выбрать подходящую категорию и дополнить список минус-фраз.

Если надо, измените настройки и просмотрите новые примеры или скачайте обновленную версию файла. Сохранять изменения в группе при этом не обязательно.

Помните, любое сужение таргетингов, в том числе и отключение категорий автотаргетинга, снижает охваты и может сказаться на эффективности кампании. Отключать категорию стоит, только если она неэффективна, например превышает среднюю цену за установку или приносит нецелевые переходы.

## Как настроить автотаргетинг в кампании

Автотаргетинг доступен на поиске и в сетях для кампаний:

Единая перфоманс-кампания

Конверсии и трафик для продвижения сайта

Продвижение приложений

Автотаргетинг — обязательное условие показа для кампаний на поиске, в Картах или на поиске и в сетях. В каждой группе объявлений нужно выбрать хотя бы одну категорию запросов. При переключении места показа с РСЯ на поиск или Карты автотаргетинг будет включен автоматически в каждой группе на **все категории** запросов. Лучше при смене мест показа проверять его настройки.

![](https://cdn-viewer.diplodoc.com/docs-assets/support-direct-pro/rev/r20512751/ru/_assets/autotargeting-category-epc.png)

1. Для работы автотаргетинга на поиске выберите категории запросов, в которых он будет включен.

Если в группу добавлены объявления, для категорий показываются примеры запросов, по которым будет срабатывать автотаргетинг.

2. В блоке **Упоминание бренда в запросах на Поиске или в Картах** выберите, какие запросы будут отбираться для показа объявлений — с упоминанием вашего бренда, бренда конкурентов или вообще без брендов. Например, вы можете использовать автотаргетинг в отдельных кампаниях для брендовых запросов.

Чтобы показывать объявления без фильтрации по бренду, включите все опции.

Включить автотаргетинг также можно на странице кампании или на вкладке **Ставки и фразы**.

Выбрать обновленные категории запросов и настройки упоминания бренда сразу в нескольких группах объявлений можно с помощью [массовых действий](https://yandex.ru/support/direct/ru/campaigns/groups-edit), в [Директ Коммандере](https://yandex.ru/support/direct-commander-new/editing/autotargeting.html) и [API Яндекс Директа](https://yandex.ru/dev/direct/doc/dg/best-practice/auto-targeting.html).

#### Как отключить автотаргетинг

Полностью отключить автотаргетинг можно для кампаний с показами только в РСЯ:

1. Перейдите в настройки группы.
2. В блоке **Автотаргетинг** отключите опцию.

![](https://cdn-viewer.diplodoc.com/docs-assets/support-direct-pro/rev/r20512751/ru/_assets/autotargeting-disable.png)

Для кампаний с показами на поиске и в Картах нельзя отключить автотаргетинг, но можно ограничить категории запросов, в которых он будет включен.

При настройке кампании для продвижения сайта через [Мастер кампаний](https://yandex.ru/support/direct/ru/campaign-master/about) автотаргетинг будет включен по умолчанию и выбраны все [категории](https://yandex.ru/support/direct/ru/impression-criteria/autotargeting#categories).

#### Как отключить автотаргетинг

При настройке продвижения через Мастер кампаний нельзя полностью отключить автотаргетинг, но можно ограничить категории запросов, в которых он будет включен.

Чтобы отключить категории автотаргетинга:

1. В блоке **Определите аудиторию** для параметра **Аудитория** выберите **Настроить вручную**.

2. В блоке **Минус-слова и исключения** выберите категории, по которым не хотите показывать объявления:
   - **Узкие запросы**;
   - **Широкие запросы**;
   - **Альтернативные запросы**;
   - **Сопутствующие запросы**;
   - **Запросы с упоминанием вашего бренда**;
   - **Запросы с упоминанием брендов конкурентов**.

![](https://cdn-viewer.diplodoc.com/docs-assets/support-direct-pro/rev/r20512751/ru/_assets/autotargeting-category.png)

При настройке продвижения приложения через [Мастер кампаний](https://yandex.ru/support/direct/ru/products-mobile-apps-ads/create) автотаргетинг будет включен по умолчанию. Вы можете управлять [категориями автотаргетинга](https://yandex.ru/support/direct/ru/impression-criteria/autotargeting#categories), но показы по целевым запросам отключить нельзя.

Чтобы выбрать категории автотаргетинга:

1. В блоке **Определите аудиторию** откройте **Дополнительные настройки аудитории**.
2. Выберите **Категории таргетинга**, по которым хотите показывать объявления.

#### Как отключить автотаргетинг

При настройке продвижения приложения через Мастер кампаний нельзя полностью отключить автотаргетинг, но можно ограничить категории запросов, в которых он будет включен.

При настройке продвижения приложения через [Единую перфоманс-кампанию](https://yandex.ru/support/direct/ru/products-mobile-apps-ads/upc/about) подключение автотаргетинга будет таким же, как в Единой перфоманс-кампании.

Примечание

Любые изменения автотаргетинга (включение, отключение, изменения категории запросов) могут применяться в течение суток. До этого объявления будут показываться в соответствии со старыми настройками.

## Управление ставками в ручной стратегии

При использовании ручной стратегии задайте ставку для автотаргетинга на поиске. В сетях ставка назначается автоматически.

Для автотаргетинга на поиске по умолчанию подключена автоматическая ставка. Она рассчитывается как средневзвешенное значение ставки в группе по кликам до применения корректировок:

Ставка = (Bid1 × Clicks1 + Bid2 × Clicks2 + ... + Bid(n) × Clicks(n)) **/** (Clicks1 + Clicks2+ ... + Clicks(n)), где

- Bid — ставка по фразе;
- Clicks — количество кликов.

> Например, в группе две ключевые фразы:
>
> 1. _Купить путешествие в космос_ — ставка 50 руб., 5 кликов;
>
> 2. _Купить путешествие на Марс_ — ставка 100 руб., 10 кликов.
>
>
> Автоматическая ставка для автотаргетинга в группе составит: (50 × 5 + 100 × 10)/15 = 83,3 руб.

Автоматическая ставка не может превышать максимальную ставку в группе по [одной из ключевых фраз](https://yandex.ru/support/direct/ru/new-interface/bid-wizard#for-keywords). Значение постоянно обновляется, так как рассчитывается не только от ставок, но и от количества кликов по каждой фразе в группе.

Чтобы назначить ставку вручную:

1. В списке кампаний отметьте нужные кампании и перейдите на вкладку **Ставки и фразы**.

2. В строке `--автотаргетинг` нажмите значок ![](https://cdn-viewer.diplodoc.com/docs-assets/support-direct-pro/rev/r20512751/ru/_assets/bids-corr.png) рядом со значением ставки.

3. Измените на «Ручная ставка», введите ставку и нажмите **Применить**.

Также изменить ставку можно через [Мастер ставок](https://yandex.ru/support/direct/ru/new-interface/bid-wizard), [Директ Коммандер](https://yandex.ru/support/direct/ru/alternative-interfaces/direct-commander) или [API Яндекс Директа](https://yandex.ru/support/direct/ru/alternative-interfaces/api).

К автоматической ставке, как и к ставкам по фразам, будут применяться [все корректировки](https://yandex.ru/support/direct/ru/impressions/bids-adjustment), настроенные на уровне кампании или группы.

Мы рекомендуем назначать ставку для автотаргетинга сопоставимую со ставками по ключевым фразам.

Если в группе не настроены ставки по фразам, алгоритмы Директа сами подберут оптимальную ставку.

## Как анализировать эффективность автотаргетинга

Статистику по автотаргетингу вы можете посмотреть в [Мастере отчетов](https://yandex.ru/support/direct/ru/statistics/new-reports-wizard) и в отчете [Поисковые запросы](https://yandex.ru/support/direct/ru/statistics/library/search-queries).

#### Мастер отчетов

Добавьте в отчет группировку **Тип условия показа** и метрики **Показы**, **CR**, **CPA**, **Конверсии**. Вы увидите общую статистику показов. Обратите внимание на столбец **Тип условия показа**: если объявление было показано по автотаргетингу, там будет стоять соответствующая отметка.

Постройте отчет с группировкой **Категория запроса** и тем же метрикам (Показы, CR, CPA, Конверсии). Вы увидите статистику показов по подобранным фразам по всем категориям.

Если хотите получить данные по каждой категории запросов — добавьте в отчет условие фильтрации **Категория запроса** и выберите нужные.

Чтобы посмотреть данные по категориям таргетингов с упоминанием брендов — изучите данные в столбце с группировкой **Упоминание брендов** в запросах.

Сравнивайте конверсии и цену цели для ключевых фраз и автотаргетинга в различных категориях. Если цена цели для автотаргетинга получается слишком высокой, понижайте для него ставку.

При необходимости можно добавить нерелевантные запросы в список минус-фраз напрямую из [отчета](https://yandex.ru/support/direct/ru/statistics/new-reports-wizard/data-table/mass-action#negative-keywords).

#### Поисковые запросы

По умолчанию в отчет уже добавлены необходимые для анализа группировки и метрики, с их помощью вы можете проанализировать, по каким поисковым запросам показывались ваши объявления. Обратите внимание на столбец **Тип условия показа**: если объявление было показано по автотаргетингу, там будет стоять соответствующая отметка.

В столбце с группировкой **Категория запроса** вы увидите статистику показов по подобранным фразам по всем категориям.

Если получить данные по каждой категории запросов, добавьте в отчет условие фильтрации **Категория запроса** и выберите нужные.

Чтобы посмотреть данные по категориям таргетингов с упоминанием брендов, изучите данные в столбце с группировкой **Упоминание брендов в запросах** дополнить данные по категориям таргетинга упоминанием брендов.

Добавляйте нерелевантные запросы в список [минус-фраз](https://yandex.ru/support/direct/ru/keywords/negative-keywords).

Специалисты отдела клиентского сервиса могут вас проконсультировать только по кампаниям того логина, с которого вы обращаетесь. Логин можно увидеть, если открыть [ya.ru](http://ya.ru/) на соседней вкладке браузера. Специалист получит доступ к вашим данным только при обработке обращения.

Сканируйте QR-код или нажмите на него для перехода по ссылке.
